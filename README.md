# 声账 VoiceLedger · 0.6 Beta

这是手机优先的 GitHub/PWA 测试版。0.6 的核心变化是：**拍照识别改为火山引擎“通用文字识别（OCRNormal）”云端 OCR**，不再使用浏览器内 Tesseract，也不再依赖付费视觉大模型。

## 0.6 保留的功能

- 有声书项目：正式书名、文件简称、甲方、平台、角色、单价、项目状态
- 拍照 / 相册导入 + 手动新增记录
- 同一本书自动归档、当前进度、累计成品时长、应收金额
- 今日、本月、指定月份、今年、全部历史统计
- 按书 / 平台 / 甲方统计
- 未结算 / 部分结算 / 已结清，结算到集数、实际到账、结算历史
- 返音 / 反音过滤
- JSON 数据导出 / 导入备份
- PWA 图标和主屏幕安装

## 0.6 OCR 链路

1. iPhone 拍照或从相册选图。
2. GitHub 页面把压缩后的图片发送到你自己的 Cloudflare Worker。
3. Worker 用保存在 Secret 里的火山引擎 AK/SK 调用 `OCRNormal`。
4. 火山 OCR 返回文字、行坐标和置信度。
5. Worker 以“文件名行”为锚点，用上下相邻文件行的中点划分记录区域，只在本条区域中寻找时长。
6. 文件简称再与声账里已有的简称做精确 / 近似匹配。
7. 返音 / 反音被过滤；结果回到手机供你确认后再保存。

这仍然是测试版：云端 OCR 的真实准确率需要用你的真实火山引擎账号跑图验证。

## 部署

- GitHub Pages：把本目录除 `cloudflare-worker` 外的文件上传到仓库根目录即可。
- 云端 OCR：按 `CLOUD-OCR-SETUP.md` 配置一次 Cloudflare Worker 和火山引擎 AK/SK。

现有 0.2～0.5 数据继续沿用原来的本地存储键，不需要重新建书。
