# 声账 VoiceLedger · 0.8 Beta

0.8 是「信息架构重构版」。0.6 已经稳定的 **火山引擎 OCRNormal + Cloudflare Worker** 识别链路保持不动；0.7 的记录管理、重复检测、结算、目标、年度统计和导出能力全部保留。0.8 的重点是：功能越来越多以后，声账依然要快、清楚、能长期用下去。

## 0.8 核心变化

- **首页变成可交互仪表盘**
  - 顶部“今天 + 拍照识别”继续保留。
  - 今日目标、本月目标、本月成品、本月应收都可以点击进入明细。
- **主导航重新收纳**
  - 底部只保留：首页 / 书库 / 拍照 / 结算 / 统计。
  - 设置移到右上角齿轮，不再占用高频主导航位置。
- **书库增加排序**
  - 保留状态、平台、甲方筛选。
  - 新增默认顺序、成品时长、累计应收、小时单价、建档时间排序。
  - 非默认排序支持升序 / 降序切换。
- **结算中心重构**
  - 支持“按书籍 / 按甲方”两种视角。
  - 支持平台、甲方、结算状态筛选。
  - 支持未收金额、累计应收、最近记录、小时单价排序。
- **统计页重构**
  - 首页只保留四个核心数字和三个清晰入口。
  - 往期统计进入二级页面：本月、今年、指定年份、指定月份、自定义日期、全部历史。
  - 年度报告进入独立二级页面。
  - 分类统计只显示当前选择的一种：按书籍 / 按甲方 / 按平台。
- **0.6 → 0.7 旧数据工作日迁移修复**
  - 对符合安全条件的旧记录，使用真实 `createdAt` 按当前工作日切换时间重新判断工作日期。
  - 默认 06:00 切日，因此午夜后到 06:00 前的旧记录可正确回到前一个工作日。
  - 如果旧记录本来就是手动指定到其他日期，则不自动改动。
- **版本更新日志**
  - 设置内新增 0.1 ～ 0.8 的版本日志，并从 0.8 起持续维护。

## 继续保留的 0.7 能力

- 重复记录：完全重复自动跳过；同集数不同时长要求选择替换或新增。
- 录音记录：查看、编辑、删除、最近删除恢复、撤销上次批量导入。
- 固定文件简称 → 正式书名映射。
- 返音 / 反音过滤。
- 自定义工作日切换时间，默认 06:00。
- 今日 / 本月工作目标。
- 结算到集数、实际到账、未结算 / 部分结算 / 已结清。
- JSON 完整备份 / 恢复。
- CSV 流水导出，可按全部、年份、月份、甲方、书籍导出。

## 从 0.7 升级

只覆盖 GitHub Pages 前端文件即可。继续沿用 `voiceledger_02_data` 本地数据键和 `voiceledger_07_work_settings` 工作设置键。

**不要重建 Cloudflare Worker，也不要重新设置火山 AK/SK。** 已经可用的 OCR 后端保持原样。

升级前仍建议先导出一份 JSON 备份。

## 部署

把本目录中的前端文件上传 / 覆盖到原 VoiceLedger GitHub Pages 仓库根目录。部署完成后刷新声账；若 PWA 仍显示旧缓存，关闭后重新打开，Service Worker 会使用新的 `voiceledger-0.8-beta` 缓存。
