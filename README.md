# 声账 VoiceLedger · 0.7 Beta

0.7 是「工作流完善版」。0.6 已经跑通的 **火山引擎 OCR + Cloudflare Worker** 保持不动；这一版重点把 OCR 后面的真实工作数据变得可长期管理、可纠错、可追账、可回看。

## 0.7 新增

- **重复记录检测**
  - 同一本书 + 相同起止集 + 相同时长：标记“已记录”，保存时自动跳过，只录新的。
  - 同一本书 + 相同起止集但时长不同：明确提示冲突，由你选择“替换旧记录”或“仍然新增”。
- **录音记录管理**
  - 在每本书详情里直接查看并编辑录音记录。
  - 可修改书籍、起止集、时长、工作日期。
  - 删除后进入“最近删除”，可恢复。
  - 首页支持“撤销上次导入”，整批撤销本次新记录，并恢复本次被替换的旧记录。
- **结算中心**
  - 单独查看累计应收、累计已收、当前未收。
  - 按甲方 / 工作室汇总欠款。
  - 列出所有未结清书籍，可直接记结算。
- **长期时间统计**
  - 本月、今年、指定年份、指定月份、自定义日期、全部历史。
  - 指定年份时可一键跳到 1～12 月。
  - 年份会根据真实数据自动出现，不用以后再专门加“去年/前年”。
- **年度报告**
  - 全年成品、应收、到账、年末未收、工作天数、日均成品、月均应收。
  - 最忙月份、收入最高月份、收入最多甲方、投入时间最多的书。
  - 12 个月工作量小图。
- **工作目标**
  - 今日成品时长目标。
  - 本月成品时长目标。
  - 首页实时显示完成度。
- **自定义工作日**
  - 默认 **06:00** 才切换新的一天。
  - 例如 9 月 22 日凌晨 01:30 的工作，会统计到 9 月 21 日。
  - 设置里可自行修改切换时间。
- **数据导出**
  - JSON：完整备份 / 恢复，继续兼容旧数据。
  - CSV：Excel / Numbers 可直接打开，可按全部、年份、月份、甲方、书籍导出。

## 0.6 已稳定并继续保留

- 火山引擎 OCRNormal 云端识别。
- Cloudflare Worker 中转，AK/SK 不进入 GitHub 前端。
- 正式书名 + 固定文件简称映射。
- 返音 / 反音过滤。
- 书库、平台、甲方、角色、单价、项目状态。
- 今日 / 本月统计、按书 / 平台 / 甲方统计。
- 未结算 / 部分结算 / 已结清、结算到集数、实际到账、结算历史。

## 从 0.6 升级

**只需要更新 GitHub Pages 的声账前端文件。**

你已经搭好的 `voiceledger-ocr` Cloudflare Worker 和火山 AK/SK **不用重建、不用重新配置、不用重新部署**。

0.7 继续使用原来的 `voiceledger_02_data` 本地数据键，因此 0.6 已经录入的书籍、录音和结算记录会继续保留。0.6 以前的记录会保持原来的工作日期；0.7 新录入的记录开始使用“工作日切换时间”规则。

## 部署

把本目录前端文件上传/覆盖到原 VoiceLedger GitHub Pages 仓库根目录。建议保留一次 0.6 JSON 备份再升级。
