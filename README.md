# 声账 VoiceLedger · GitHub 0.2.2

手机优先的有声书工作记录 PWA。

## 0.2.2 重点修正

- 返音 / 反音记录在 OCR 阶段直接过滤，不计入时长与收入。
- OCR 书名简称会优先匹配已建立项目，并允许轻微错字（例如“不是疯笔”匹配“不是疯批”）。
- 时长与文件行按版面区块匹配，不再跨到相邻文件；无法安全匹配时宁可留空让用户确认。
- 新建书籍后，拍照结果里的“归入书籍”立即刷新并重新尝试自动匹配。
- 时长支持纯数字输入：`012523` → `01:25:23`，`2523` → `25:23`；仍兼容 `25`、`25:23`、`01:25:23`。
- 书库新增“平台”和“甲方 / 工作室”筛选。
- 统计新增往期视图：本月、上月、今年、全部、指定月份。
- 统计新增按平台、按甲方汇总；点击汇总可跳到对应书库。
- 新增设置页：JSON 数据备份导出 / 导入，便于升级版本或把数据发给 ChatGPT 检查。

## 数据

继续沿用 `voiceledger_02_data` 本地数据键，直接从 0.2 / 0.2.1 升级不会主动清空已有书籍、录音或结算记录。

旧月份的数据一直保存在本地；“本月”只是统计筛选，不会在跨月时删除历史记录。

## GitHub Pages

把本目录全部文件上传到仓库根目录，在 GitHub Pages 中选择从主分支根目录部署即可。
