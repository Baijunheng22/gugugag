# 声账 VoiceLedger · GitHub 0.2

这是**手机优先**的 GitHub / PWA 试用版，目前只做「有声书」板块。

## 0.2 已实现

- iPhone 拍照识别电脑屏幕，或从相册选择截图/照片
- 一张照片识别多条录音记录
- OCR 后先进入确认页，可改书籍、简称、日期、集数和时长
- 「文件简称 → 正式书名」自动匹配
- 每本书独立项目：正式书名、简称、甲方、平台、角色类型、角色名、小时单价、项目状态
- 自动累计每本书的成品时长
- 自动显示当前录制进度
- 自动计算累计应收
- 今日 / 本月成品时长和应收统计
- 结算记录：结算到第几集、本次实际到账、结算日期
- 自动计算未结算 / 部分结算 / 已结清，以及应收 / 已收 / 未收
- 重复记录提醒
- PWA：可从 Safari 添加到主屏幕

## 部署到 GitHub Pages

1. 在 GitHub 新建仓库，推荐仓库名：`VoiceLedger`。
2. 把本文件夹里的所有文件上传到仓库根目录。
3. 打开仓库 `Settings` → `Pages`。
4. `Build and deployment` 选择 `Deploy from a branch`。
5. Branch 选择 `main`，目录选择 `/ (root)`，保存。
6. 等待 GitHub 给出 Pages 地址，用 iPhone Safari 打开。
7. Safari 分享按钮 → `添加到主屏幕`。

## 关于拍照识别

0.2 使用浏览器端 Tesseract.js 进行 OCR。第一次识别需要联网加载中文 + 英文识别模型，之后浏览器通常会缓存相关资源。照片越正、文字越清楚、屏幕反光越少，识别越稳定。

OCR 不是直接入账：识别结果会先展示给你确认，所以数字或文字认错时可以手动改。

## 数据

当前试用版数据保存在浏览器本地存储中。不同浏览器 / 不同设备不会自动同步。这一版先用于体验工作流，后续再根据实际使用迭代。
