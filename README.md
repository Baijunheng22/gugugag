# 声账 VoiceLedger · GitHub 0.3 Beta

这是 0.3 测试版，不是 1.0 正式版。当前继续只做“有声书”板块，并沿用 0.2.2 的书库、平台/甲方筛选、统计、结算、手动记录和 JSON 备份功能。

## 0.3 这次只重点改两件事

### 1. OCR 改成“同一条记录内配对”

0.2.2 为了避免把下一条文件的时长串到上一条，限制过严，结果出现了书名和时长大量丢失。0.3 改成多阶段识别：

1. 先对整张照片做两遍 OCR：原图一遍、轻度增强图一遍。
2. 用 OCR 的版面坐标先找到每个“集数范围”所在的文件行。
3. 以相邻文件行作为边界，每一条记录只在自己的纵向区域内寻找时长，不跨到下一条。
4. 原图和增强图的结果按“集数 + 屏幕位置”合并，减少单次 OCR 的误识别。
5. 如果书名没有可靠识别，再把这一条文件名区域单独裁出来，做 7/12 两种版式的二次 OCR，然后用已经建立的文件简称做模糊匹配。
6. 如果某条时长仍为空，再只裁它自己右侧的时长区域，并限制为数字和冒号重新识别。
7. “返音 / 反音”仍然作为忽略项；二次裁切识别也会继续检查它。

这版的原则是：宁可某一项留空让你确认，也不要把下一条记录的时长错配过来。

### 2. App 图标 / Logo

新增 0.3 版本化图标，并在 App 顶部直接显示 Logo。PWA manifest、Apple Touch Icon 和 favicon 都改成新的文件名，减少 iPhone 沿用旧网页图标缓存的情况。

如果你的主屏幕上已经有旧版“声账”，iOS 可能仍然保留旧图标。最稳妥的方法是：

- 先删除旧的主屏幕“声账”快捷方式（不会删除 Safari 中的 VoiceLedger 数据）；
- 用 Safari 打开更新后的 GitHub Pages；
- 再次“添加到主屏幕”。

## 数据兼容

仍沿用 `voiceledger_02_data` 本地数据键。正常从 0.2 / 0.2.1 / 0.2.2 升级到 0.3，不会主动清空已有书籍、录音记录或结算记录。

设置页的 JSON 导出 / 导入继续保留。升级前如果里面已经有重要数据，建议先导出一次备份。

## GitHub Pages

把这个文件夹里的内容放到仓库根目录，然后在 GitHub：

`Settings → Pages → Deploy from a branch → main / root`

发布完成后，用 iPhone Safari 打开 GitHub Pages 地址即可。
