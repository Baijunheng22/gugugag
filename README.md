# 声账 VoiceLedger · 0.9 Beta

0.9 是「多来源工作台 + 视觉质感升级版」。AU 仍沿用已经稳定的拍照 OCR 工作流；新增 **呱呱录音宝月账** 作为独立工作来源。两个来源的项目互不混录，但会在月度、年度和总账层统一汇总。

## 0.9 重点更新

- **呱呱月账导入**
  - 先选择账单归属月份（默认当前工作月），再拍照或从相册选择账单。
  - 云端 OCR 识别：收入来源、书籍名称、工作类型、工作量、单价、官方金额、结算方式、结算范围、结算日期。
  - 所选月份由用户掌控；OCR 日期仅用于校验，跨期/月份不一致会提示，不会擅自改账期。
  - 官方金额直接保存，绝不使用“显示工作量 × 单价”重新计算金额。
  - 呱呱界面工作量仅显示两位小数，因此单价大于 0 时，声账会用“官方金额 ÷ 单价”还原更精细的有效时长，同时保留原始工作量字段。
  - 同一月份、同一账单行再次导入会自动识别并跳过。

- **AU / 呱呱多来源统计**
  - 项目创建时选择来源：AU 或呱呱录音宝；同一本项目不会跨来源合并。
  - “今日”只统计有明确工作日期的 AU 记录，呱呱月账不会被伪造成某一天的工作量。
  - “本月 / 年度 / 全部历史”会汇总 AU + 呱呱，并可在统计页按来源拆开看。
  - CSV 同时导出 AU 日记录和呱呱月账，但保留来源字段。

- **长期项目管理**
  - 新增全局搜索：书名、简称、甲方、平台、呱呱账单均可检索。
  - 项目支持置顶，常用连载书可以固定在前面。
  - 项目支持归档，历史项目不再挤占日常书库。
  - 首页新增最近动态，记录新增项目、AU 导入、呱呱月账、结算、置顶/归档等近期操作。

- **数据保险箱**
  - 第一次从旧版本进入 0.9 时，在任何迁移写回之前自动保存“升级前快照”。
  - 导入 JSON 备份之前也会自动保存当前数据。
  - 恢复快照之前再保存一次当前数据。
  - 设置中可查看、导出、恢复最近的自动快照。
  - 这解决的是版本升级安全问题；它不替代手动 JSON 外部备份。清除浏览器网站数据仍可能同时清除本地数据与本地快照。

- **视觉与动效**
  - 页面切换使用 View Transitions（浏览器支持时），并增加克制的滑入/淡入过渡。
  - 卡片、按钮、底栏、弹层增加按压与进入动效。
  - 支持“减少动态效果”系统偏好，开启后自动缩减动画。
  - 新增来源徽标、搜索界面、呱呱导入页与数据保险箱视觉层级。

## 从 0.8 升级

1. **先手动导出一份 0.8 JSON 备份**。0.9 自带自动升级前快照，但外部 JSON 仍是最稳的保险。
2. 把本目录前端文件覆盖到原 VoiceLedger GitHub Pages 仓库。
3. **这次还需要把 Cloudflare Worker 更新到 0.9 一次**，因为旧 Worker 只认识 AU 文件列表，不认识呱呱账单表格。
4. 不需要重新创建 Worker，不需要重配 AK/SK。只替换 Worker 代码并让原 GitHub→Cloudflare 部署跑一次即可。
5. 更新后打开声账：旧 AU 项目和记录会继续沿用；旧项目默认来源为 AU。

> 0.9 不会把测试数据或用户备份写进安装包。数据仍来自当前浏览器本地存储，版本包只包含程序代码。

## Cloudflare Worker

主包内 `cloudflare-worker/worker.js` 已包含：

- 既有 AU OCR 解析（保持兼容）
- 新的 `mode: "guagua"` 月账表格解析
- `/health` 返回 `version: "0.9"` 和 `features: ["au", "guagua"]`

也可以使用单独提供的 `VoiceLedger-Cloudflare-Worker-GitHub-0.9.zip` 更新 Worker 仓库。

## 本地数据

主要业务数据仍使用浏览器本地存储；0.9 新增独立快照存储。请继续定期导出 JSON，尤其在大量录入或版本升级之前。
