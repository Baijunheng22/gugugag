# 声账 VoiceLedger — V1

一个面向配音工作的本地桌面工作账本。V1 先完成「有声书」板块：项目归档、MP3 扫描、成品时长累计、当前进度、按小时计价、甲方/平台/角色信息、结算记录和今日/本月统计。

## V1 已实现

- 正式书名 + 文件简称/别名映射：例如 `双修` 自动归入《双修之天下第一》
- MP3 扫描并读取真实时长
- 从文件名识别集数范围：`双修 394-414 白珺珩.mp3`
- 同一本书自动归档、累计成品时长和理论应收
- 当前进度：自动取已导入记录里的最大结束集数
- 今日 / 本周 / 本月成品时长与理论应收
- 项目资料：甲方、平台、角色类型、角色名、单价、项目状态
- 平台和角色类型下拉选择，也允许自定义
- 结算流水：结算到第几集、实际结算金额、日期、备注
- 自动显示：未结算 / 部分结算 / 已结清
- 自动汇总：累计应收、累计已收、未收差额
- 防重复导入：基于文件内容片段 + 文件大小生成指纹，同一文件换目录后也能识别
- 本地 SQLite 数据库，不上传云端

## 文件命名规则（V1）

V1 只处理正式成品，不考虑返音、补录等杂项。

推荐格式：

```text
简称 起始集-结束集 姓名.mp3
```

例如：

```text
双修 394-414 白珺珩.mp3
受气包 151-160 白珺珩.mp3
```

先在「项目」里建立《双修之天下第一》，把 `双修` 填到“文件简称/别名”中，以后扫描时会自动归档。

## 运行

Windows 最省事：双击 `run.bat`。

或者手动：

```bash
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

首次运行会在程序目录创建 `voiceledger.db`。
